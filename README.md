# האתר של קאנטרי קהילתי בארבור: ערכת ניהול ואחזקה

הכתובת: https://countrybarbour.co.il

אתר סטטי פשוט: אין שרת, אין מסד נתונים, אין מערכת לתחזק. כל התוכן יושב בקובץ אחד, וכל השאר נבנה ממנו לבד.

## שלוש דרכים לעבוד

| מי | איך | מתי |
|---|---|---|
| צוות בארבור | הדשבורד: countrybarbour.co.il/admin | אירועים, טקסטים, תמונות, שעות |
| מעצב או בונה אתרים | עריכה בקבצים שבמאגר | עיצוב, מבנה, עמודים חדשים |
| כל אחד בגיטהאב | עריכת `content/site.json` ישירות באתר של גיטהאב | תיקון מהיר |

אחרי כל שמירה האתר נבנה מחדש לבד תוך דקה–שתיים. פעם ביום הוא נבנה שוב, כדי שאירועים שעברו ירדו מ"השבוע בבארבור".

## הדשבורד

1. נכנסים ל־countrybarbour.co.il/admin
2. בפעם הראשונה מדביקים מפתח גישה של גיטהאב. ההוראות ליצירת המפתח מופיעות בדף. המפתח נשמר רק בדפדפן של מי שהדביק אותו.
3. עורכים, ולוחצים "שמירה ופרסום".

## מה יש במאגר

| קובץ / תיקייה | מה זה |
|---|---|
| `content/site.json` | כל התוכן: כותרת, פתיחה, אירועים, מחלקות, שעות, פרטי קשר |
| `tools/build.py` | בונה את קובצי האתר מתוך התוכן |
| `*.html` | העמודים הבנויים. לא עורכים אותם ידנית, הם נדרסים בכל בנייה |
| `site.css` | כל העיצוב |
| `site.js` | התנועה: מעבר בין תמונות, פס המחלקות, התפריט |
| `m/` | צילומים וסרטונים |
| `logo/` | הלוגו הראשי וסמלי המחלקות |
| `fonts/` | הגופן (Heebo), מאוחסן מקומית |
| `admin/` | הדשבורד |
| `.github/workflows/build.yml` | הבנייה האוטומטית |
| `CNAME` | חיבור הדומיין. לא למחוק |

## עבודה של מעצב

```
git clone https://github.com/center-barbour/countrybarbour.co.il
cd countrybarbour.co.il
python3 tools/build.py          # בונה את העמודים
python3 -m http.server 8000     # תצוגה: http://localhost:8000
```

- טקסט ותמונות: `content/site.json`
- עיצוב: `site.css`. צבעי המחלקות מוגדרים במשתנה `--dc`, ליד המחלקות `.t-pool` וכו׳
- מבנה העמודים: `tools/build.py`
- מחלקה חדשה: מוסיפים רשומה ל־`depts` ב־`content/site.json`. אם יש לה סמל, שמים אותו ב־`logo/badge-<מזהה>.svg` ומוסיפים את מידותיו ל־`BADGE` ב־`tools/build.py`
- דוחפים ל־`main`, והאתר מתעדכן

## כללי הבית

- **העיצוב שנבחר:** כותרת שקופה מעל פתיחה בצילום מלא, הכותרת "מקום אחד לכל מה שטוב.", פס מחלקות נע, וכל מחלקה בצבע הלוגו שלה. זו גרסת הייחוס שנבחרה בנובמבר 2026.
- **נגישות:** האתר בנוי לפי ת"י 5568 ברמה AA. לשמור על ניגודיות, טקסט חלופי, ניווט במקלדת, וכפתור עצירה לכל תנועה.
- **תמונות:** עד 1800 פיקסלים בצד הארוך, JPG. הדשבורד מקטין לבד.
- **סרטונים:** קצרים ובלי קול, עד כ־4 מגה.
- **לפני פרסום מלא:** לבדוק שאין פרטים לא מאושרים, למשל שעות לא מאומתות או צילום בלי אישור. אחר כך מבטלים בדשבורד, בלשונית "כללי", את "להסתיר מגוגל" ואת "אב טיפוס".
